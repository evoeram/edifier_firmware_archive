1 · Подключение и предохранители

Троттлинг записи≥ 300 мс между кадрами
Лимит payload64 Б (больше — только вручную)
Watchdog5 молчаний подряд → пауза
RX-окно2 с на ответ, классификация
Правила стенда: (1) при подключении НИЧЕГО не отправляется автоматически; (2) каждый исходящий кадр показывается в лог до отправки; (3) запись включается только тумблером «Разрешить запись» и работает только с классами ROUNDTRIP/PROBE; (4) класс DANGER — отдельный тумблер + подтверждение на каждый кадр; (5) watchdog приостанавливает всё, если колонка перестала отвечать.
Если в окне выбора пусто / не подключается — чек-лист: ① колонка не должна быть подключена к телефону/ПК (в подключённом состоянии она не рекламируется — разорви соединение или выключи/включи BT на телефоне); ② колонка включена и не спит; ③ Bluetooth-адаптер компьютера включён (Win+K видит устройства); ④ имя в рекламе может быть «MR5BT»/«MR3BT» без «EDIFIER» — фильтр уже ослаблен, выбирай любое, сервис отсеет; ⑤ если окно выбора вообще не появилось — открой файл двойным кликом в обычном Chrome/Edge, а не в панели.

3 · ROUNDTRIP-тесты (обратимая запись: читаем → пишем то же значение → читаем назад)

Каждый тест: 0x66/0x86/0x43 (текущее) → запись того же значения → чтение → сверка. Если значение изменилось — автоматический откат. Это доказывает, что канал записи работает, не меняя звук.
—

4 · PROBE: кандидаты доставки node_param_set (гипотезы из реверса)

READ-подобные op (0x43, 0xC6, 0xD8, …) шлются сразу, без тумблеров. Для не-READ op нужно снять Dry-run и включить «Разрешить запись» (карточка 3).
Кандидат 0x2B (десятичный 43) — гипотеза «доставка node_param_set по app-каналу». Гейн-блок с 0 дБ безобиден: это заводское значение SET_HP_GAIN idx0. Проба шлёт кадры ПО ОДНОМУ, ждёт RX-окно 2 с и классифицирует ответ. Любой ACK/эхо = кандидат подтверждён.
—

5 · DANGER (по умолчанию ВЫКЛЮЧЕНО, требует двойного включения)

Эти команды меняют состояние и/или перезагружают колонку. 0x92 перевозит устройство в другой кодек-режим (может ребутнуть). DUT-строки вида SAV/SET пишут в flash. Сырой кадр уходит как есть — проверяй байты. Каждый клик требует подтверждения.

6 · DUT/AT-пробник (автоматический перебор команд из прошивки)

Команды взяты из строк прошивки (f_tst_btn_sta @06018a8e). Транспорт канала не подтверждён: пробник шлёт каждую команду всеми выбранными EOL-вариантами и слушает 1,5 с — ответ может прийти текстом (ASCII) или кадром BB. Найденные живые комбинации подсвечиваются в логе и в таблице. READ-набор только читает состояние.
