# MR5 1.0.3 — Трассы сигнала (Bluetooth / Line In / XLR / AUX → выходы)

Дата: 2026-11-18. Обозначения: ✅ доказано кодом/конфигом; ⚠️ реконструкция
по косвенным данным (именам узлов и конфигов).

## 1. Bluetooth A2DP (музыка) ⚠️

```
BT стек (лмп/hci …) → A2DP_RX6/A2DP_RX7 (декодер SBC/AAC/LDAC, SDK-библиотеки,
   mpegaudio_synth_full @06056456 и др.)
   → MIXER1 → EQ (слот MusicEq / EQ17 / BassShelf-TrebShelf по настройке)
   → DRC5 (MusicDrc) → digvol Vol_BtmMusic / Vol_BtmMusic2 (кривая −70…−7 дБ)
   → DAC-каналы → усилители
```
Доказательства: имена `a2dp_dec`, `A2DP_RX6/7`, `MusicEq`, `MusicDrc`,
`Vol_BtmMusic(2)`; кривые громкости в stream.bin; декодер-функции в
b3_signatures. Конфиг `Vol_BtmMusic` GAIN-блок 136 Б (32 шага дБ).

Параллельно `EnergyMusic` (param 1/3) следит за энергией BT-потока
(GAIN-конфиг: порог 3000, окно 100).

## 2. Bluetooth ESCO (разговор) ⚠️

```
микрофон → esco_adc (d06d/1; АЦП-конфиг esco_adc: 4 канала × {0x0e,8})
        → EscoUlEq (слот 10, аплинк-коррекция: bypass@100×2)  → esco_tx (BT)
BT      → EscoDlEq (слот 11, даунлинк: t7@40+t8@18000, плоско)
        → digvol Vol_BtcCall → DAC
```
Строки `esco_tx`, `esco_adc`; вызовы `f_esco_adc` @0600de08 из BT-обработчиков
(0601101c, 0601223a); `DrcCalcTimeFactor`-ветки для call-режима.

## 3. Line In (задняя панель, линейный вход) ⚠️

```
RCA Line In → АЦП (ADC13 / linein-узел) → EQ (Desk_Acoustic(_2) или EQDIY)
   → DRC → digvol Vol_LinMusic / Vol_LinMusic2 (кривая −63…0 дБ)
   → DAC-каналы
```
Доказательства: строка `linein` (4 ссылки: 0600a0cc, 0600b0d4 — узел
mixer-семейства; 0x060832a2/0x060832ba — оверлей, конфигурация входа),
`linein_dev` (0x060832ca), тон `tone_zh/linein.*`, кривые Vol_LinMusic(2).

## 4. XLR balanced IN (задняя панель) ⚠️

Отдельного «xlr»-узла в прошивке НЕТ. Симметричный XLR-вход заводится на тот
же АЦП-тракт, что и Line In (обработчики 0600a0cc/0600b0d4 обслуживают оба
гнезда; конфигурация в оверлее 0x060832xx, там же `linein_dev`).
Различие трактов — в усилении: для компенсации уровня симметричного входа
служит пара конфигов `AUX_DAC_GAIN2` (+6.5 дБ) против `AUX_DAC_GAIN`
(0/−1.3 дБ). Прямого кода выбора «XLR vs RCA» в app-слое не найдено —
вероятно, выбор уровня фиксируется аппаратно/заводской конфигурацией.

## 5. AUX (фронтальный 3.5 мм) ⚠️

```
AUX → АЦП → EQ → digvol (кривая Line-семейства) → DAC
```
Гейны `AUX_DAC_GAIN` (0/−1.3 дБ) применяются к DAC-тракту при активном AUX;
строка `AUX_DAC_GAIN` в стабе `f_aux_dac_gain` @06001e50, который вызывается
из обработчиков источников (0600bf94, 0600c2de).

## 6. Выходы

### 6.1 Основные каналы (три-усилитель, tri-amp) ⚠️
4 инстанса ЦАП-шаблона: `DAC2`(2), `DAC3`(21), `DAC24`(24), `DAC25`(25).
Три канала на НЧ/СЧ/ВЧ-усилители с по-полосной коррекцией — слоты
`BassShelf_LB2/LB3/LB4` и `TrebShelf_LB3/LB4` (LB-суффикс, per-way shelf),
плюс `ChannelExpand18/42` для разводки каналов (subwoofer-канал).
GAIN-конфиги `DAC24`/`DAC3` (9 Б: старт 0x32=50, 0x08 — конфиг канала).

### 6.2 Наушники (фронтальный выход) ✅
Гейн-узел `SET_HP_GAIN`: **+8.3 дБ** (нормальный) / **+2.3 дБ**
(`SET_HP_GAIN2`, пониженный) / **−90.3 дБ** (mute, второй блок SET_HP_GAIN).
Управление — `set_hp_gain` @06006390 (счётчики 0x106060+0x14/15/16,
пределы 0x33=51 шаг), вызывается из key-handler'ов (06006692, 06007bfc).
Строка `SET_HP_GAIN` в конфигах и стабе `f_jlstream` @06001e76.

### 6.3 Цифровой выход ⚠️
IIS0_TX1/TX3/TX4 (I2S-out), конфиги `IIS0_TX1/TX3` (stride 12) и
`IIS0_TX4` (stride 12) — маршрут для записи/внешнего DSP.

### 6.4 Системный тон ✅
Тоны `tone_zh/*.mp3` (power_on/off, bt_conn/bt_dconn, vol_max, key_tone,
ring, game_in/out, linein, normal) воспроизводятся через отдельную цепочку с
громкостью `Vol_SysTone`/`Vol_SysKTone` (`FUN_0606fc52`: слоты 0x10689e,
0x1068a0, default 4).

## 7. Управление выбором источника ✅ (механизм) / ⚠️ (карта режимов)

- Единая точка входа графа — `effect_nodes_open` (site 06018e4a — вызов из
  режима-обработчика); закрытие — `effect_nodes_close` (site 0603b592).
- Обработчики режимов (зона 0600bf82–0600d9d2) подключают/отключают узлы
  стабами (f_mixer7 open/close, f_aux_dac_gain, f_trebshelf_*, f_jlstream,
  f_ext_reserved) → node_param_set (`FUN_06038bd8`, 46 сайтов вызова).
- Смена источника сопровождается постом событий 0x2000d/0x2001f/0xd88 по
  цепочке узлов (`FUN_060389ae`).
- `dut_tst_cmd_handler` @0600ba7c — тестовый режим (DUT/TST), переключает
  те же узлы принудительно (строки «DUT+TST+TXS+0» и т.п.).
