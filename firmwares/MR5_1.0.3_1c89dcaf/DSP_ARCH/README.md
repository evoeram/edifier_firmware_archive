# MR5 1.0.3 — DSP-архитектура (JieLi jl701n / pi32v2)

Каталог результатов разбора DSP-подсистемы MR5 1.0.3 (продолжение планов
`REVERSE_ENGINEERING_PLAN_NEW.MD` / `_NEW2.MD`; база — C1.2 audio-graph из
`source/findings/C1_audio_graph.md`).

## Файлы

| Файл | Содержание |
|---|---|
| `DSP_ALGORITHMS.md` | Все DSP-алгоритмы: EQ (би-квад, типы 0–8), DRC (peak-follower), темброблоки, громкость, микшер, конфиг-хранилище |
| `SIGNAL_PATHS.md` | Трассы сигнала: Bluetooth (A2DP/ESCO), Line In (задний), XLR balanced (задний), AUX (фронтальный) → ЦАП/наушники; граф узлов и переключение источников |
| `POWER_AMP.md` | Управление выходными трактами: ЦАП-узлы, гейны SET_HP_GAIN / AUX_DAC_GAIN, GPIO (PORTA 0xfd5000), tri-amp |
| `EQ_TABLES.md` | Полные таблицы коэффициентов EQ из stream.bin (Bass/Treb/Desk_Acoustic/EQDIY/ESCO) |

## Кратко — главные выводы

1. **DSP-ядро = jlstream audio-graph** (JieLi SDK). Узлы идентифицируются
   именем-строкой + crc16 (djb2, seed 0x1505, множитель 0x21) — тот же хэш
   используется и в конфиг-БД flash (`FUN_06037ba4`), и в stream.bin.
   Граф: 62 именованных узла-шаблона, 176 инстансов, 246 конфиг-дескрипторов
   (185 EQ / 2 DRC / 59 GAIN).
2. **Конфиги эффектов живут в двух местах**: значения по умолчанию — в
   `stream.bin` (ресурсный хвост, TLV tag 5), пользовательские/текущие — в
   конфиг-БД spi-flash (запись `FUN_06037cce`, чтение `FUN_06037ba4`,
   ключ = {type, crc32(name), param}).
3. **Управление выходами**: цифровые гейны через узлы
   `SET_HP_GAIN` (+8.3 дБ вкл / −90.3 дБ mute — наушники),
   `AUX_DAC_GAIN`/`AUX_DAC_GAIN2` (0/−1.3/+6.5 дБ — вход AUX),
   кривые громкости по источникам `Vol_*` (32-шаговые таблицы дБ).
   Аппаратный mute/управление PA — через PORTA GPIO (0xfd5000=OUT,
   0xfd5008=DIR): биты PA1/PA6 (функции 06006068/06006132/060061fc/060062c6).
4. **Тембр**: BassShelf = 13 шагов ±6 дБ @125 Гц (+вариант с +4 дБ @180 Гц и
   +3 дБ @4 кГц), TrebShelf = 13 шагов ±6 дБ @10 кГц, Desk_Acoustic_2 =
   пресет «полка» (pk@200 Гц −4 дБ + t4@500 Гц 0…−4 дБ), EQDIY×4 = слоты
   пользовательского EQ.
