# MR5 1.0.3 — Управление выходными трактами и усилителем (tri-amp)

Дата: 2026-11-18. Часть выводов — реконструкция (помечено ⚠️), часть
доказана кодом (✅).

## 1. Карта регистров GPIO (PORTA) ✅

Периферия маппируется как в br28 (jl701n): `ls_base = 0xfd0000`,
`map_adr(grp,adr) = (64*grp + adr)*4`. PORTA = ls_base + (64*0x50)*4:

| Адрес | Регистр |
|---|---|
| 0xfd5000 | PORTA.OUT |
| 0xfd5004 | PORTA.IN |
| 0xfd5008 | PORTA.DIR |

(Сверка: `source/../br28.h` — JL_PORTA_BASE = ls_base+map_adr(0x50,0).)

## 2. Управляющие функции-«пульсы» ✅

| Функция | Действие |
|---|---|
| `FUN_06006068` | крит.секция → PORTA.OUT \|= 0x2 (PA1); PORTA.DIR &= ~0x2; OUT &= ~0x2; затем OUT \|= 0x40 (PA6); DIR &= ~0x40; OUT &= ~0x40 |
| `FUN_06006132` | то же с PA6 (0x40) |
| `FUN_060061fc` | то же с PA6 |
| `FUN_060062c6` | то же с PA6 |

Машинный код (листинг 06006068): `[0xfd5000] |= 2 → [0xfd5008] &= ~2 →
[0xfd5000] &= ~2 → [0xfd5008] &= ~2 → [0xfd5000] |= 0x40 → [0xfd5008] &= ~0x40`
— вывод уровня с последующим переводом пина в Hi-Z (имитация open-drain).

⚠️ Интерпретация: короткие стробы PA1/PA6 — управление внешними
аналоговыми узлами (mute/enable усилителей, anti-pop при смене громкости,
либо управление LED/индикацией). Точная функция пина требует схемы устройства.

Прочие пользователи PORTA:
- 0604848c (функция 0604842a, BT-стек): `DIR &= ~0x10; OUT ^= 0x10` —
  периодический toggle PA4;
- 06048b90 (функция 06048a02): `DIR &= ~0x2; OUT ^= 0x2` — toggle PA1,
  состояние в 0x1069110;
- оверлей 0x06089ecc/0x0608a19e — тоже 0xfd5000 (RAM-копии, из B3.1).

## 3. Цепочка set_hp_gain (клавиши громкости/наушников) ✅

`set_hp_gain` @06006390 (2022 Б) — обработчик событий громкости:
- param_2 = 0 → `FUN_06006068` (строб PA1), 1 → `FUN_06006132` (PA6),
  2 → `FUN_060062c6` (PA6);
- счётчики: 0x106060+0x14 (цикл 0..0x33=51), +0x15 (циклы 8/16/24 —
  ускорение при удержании), +0x16 (0..0x33);
- по порогам вызывает `FUN_060061fc` (строб) и сбрасывает счётчик;
- защита от «залипания» (счётчик 60000 → сброс).

Вызовы: сайты 06006692, 06007bfc (клавиатурные/IR-обработчики);
`FUN_06009ebc` тоже вызывает строб PA6 (06009ee4).

## 5. Три-усилительная схема (tri-amp) ⚠️

4 инстанса ЦАП-шаблона `dccd`: DAC2(2), DAC3(21), DAC24(24), DAC25(25).
Полосная коррекция по каналам — EQ-слоты `BassShelf_LB2/LB3/LB4`,
`TrebShelf_LB3/LB4` (LB-варианты shelving), `Desk_Acoustic(_2)` —
согласуется с активной 3-полосной (НЧ/СЧ/ВЧ) схемой усилителя;
`ChannelExpand18/42` разводит каналы (в т.ч. сабвуферный сигнал).

Распределение «какой DAC → какой усилитель» из прошивки напрямую не следует
(нет строк/конфигов с именами динамиков); предлагается уточнить по
принципиальной схеме. Мьют/enable, судя по стробам PA1/PA6 и −90.3 дБ mute,
реализован комбинацией: цифровой mute (digvol/gain) + GPIO-строб.

## 6. Тон-сигналы и системная громкость ✅

`FUN_0606fc52(kind, val)`: kind<2 → слот 0x10689e, kind==2 → 0x1068a0,
иначе принудительно `f_energymusic(0)`; затем `FUN_0606fb58` (если
`*0x1064c8==3` — прочитать 6-байтный пакет `FUN_06003244`) → `FUN_0606fba0`.
`FUN_06003292` (vol_cfg_apply): читает конфиг-БД (`FUN_06037cba`), кладёт
значение в 0x104a42, формирует пакет `bb ec 68 00 01 05` @0x106e40 и
отправляет (`FUN_0600271a` — контрольная сумма + передача, канал
`FUN_06073ce6(7)`). ⚠️ Назначение пакета (внешний контроллер? TWS?)
требует уточнения.
