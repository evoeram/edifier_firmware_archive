# C1.2 — stream.bin: аудио-граф и конфиги эффектов (2026-11-18)

`stream.bin` — вложенный том ресурсного хвоста (hdr@tail+0xc394,
данные tail+0xc3b4, 61 820 Б). Это содержимое «effect_cfg»:
граф узлов + конфиги/коэффициенты. Формат — TLV-поток
`tag:u16 | len:u16 | payload` (LE).

| tag | len | содержимое |
|---|---|---|
| 0 | 0x2c0 | рёбра графа: 176 записей по 4 Б (crc16, u16); 106 crc совпадают с именами узлов |
| 2 | 0x516 | 62 имени: `tag 0x0013 \| crc16 \| param u8 \| name[16]` |
| 3 | 2 | ? (`6c 82`) |
| 4 | 0x1c | 4 ссылки `05 00 \| crc16 \| u16` |
| 5 | 0xe6c2 | хранилище конфигов (см. ниже) |
| 6/8/10 | 0x30/0x14/0x242 | хвостовые TLV (не разобраны) |

## Tag 5 — хранилище конфигов

- шапка 16 Б (`04 00 …` — версия 4);
- **246 дескрипторов × 32 Б** (все ссылаются на известные узлы): `{type u8 | crc16 | param u8 | 00 | id_a u16 (0x9660) | id_b u16 (посл. номер) | idx u8 | block_off u16 | 00 | stride u16 | 00 | нули[16]}`; типы: 1×185 (EQ, stride 200), 2×2 (DRC, stride 76), 3×59 (гейны, stride 12 и др.);
- 4+2 групповые записи (`04`/`05`/`07 \| ff×6 \| ptr u16 \| …`);
- далее — блоки значений по `block_off`/`stride`.

### Тип 1 — EQ (блок 200 Б)

Шапка 8 Б + `count` × 16 Б: `{band u16 | type u16 | freq u32 | pad u32 | Q float}`. Пример (BassShelf, 12 полос):

| band | type | freq, Гц | Q |
|---|---|---|---|
| 0 | 4 | 125 | 0.7 |
| 1 | 4 | 180 | 0.7 |
| 2 | 3 | 4000 | 0.7 |
| 3 | 2 | 238 | 0.7 |
| 4 | 2 | 505 | 0.7 |
| 5 | 2 | 1070 | 0.7 |
| 6 | 2 | 2268 | 0.7 |
| 7 | 2 | 4807 | 0.7 |
| 8 | 2 | 10190 | 0.7 |
| 9 | 2 | 21599 | 0.7 |
| 10 | 7 | 40 | 0.7 |
| 11 | 8 | 18000 | 0.7 |

### Тип 2 — DRC (76 Б, float) и тип 3 — гейны (12 Б, float)

- DRC5 (off 0x4a8c): [0.0, 0.0, -1.6, -1.6, 135.39999, 135.39999, 158.39999, 135.39999] …

Тип 3 (пример SET_HP_GAIN, off 0x4d5f): тройки float (8.2, -90.0, 0.0 … — дБ: макс/мин/шаг?).

## Выводы

1. `stream.bin` = effect_cfg: полный аудио-граф (узлы+рёбра) и параметры всех эффектов MR5.
2. Узел адресуется парой (crc16 имени, param); crc16 — тот же jl_crc16.
3. EQ-блоки — полосы (freq/type/Q), биквады DSP строит сам; гейны — float в дБ; DRC — float-наборы.
4. Привязка к коду: SET_HP_GAIN-кластер (B2), файловый API по имени `stream.bin`.
5. Не разобрано: tag 0 семантика слова w, tag 3/6/8/10, групповые записи 04/05/07, типы дескрипторов 7.
