# C2 — Громкость, защиты и фильтрация в тракте MR5 (2026-11-18)

Дополнение к C1_audio_graph.md. Источники: `stream.bin` (effect_cfg,
tools/stream_gains.py, work/eq_gains.py), листинг `disasm/mr5_app_disasm.txt`,
декомпил `ghidra_export/mr5_decomp_all.c`, строки app.bin.

## 1. EQ-блоки содержат ГЕЙНЫ полос (уточнение C1)

Формат записи полосы (16 Б): `{band:u16 | type:u16 | freq:u32 | gain:f32 (дБ) | Q:f32}`.
Ранний разбор читал `gain` как «pad». Полный дамп: work/eq_gains.py.

- **BassShelf** — 26 инстансов = лесница тона-контроля НЧ: полка (type 4)
  @125 Гц, шаг 1 дБ, **−6…+6 дБ**; idx 0–12 — только бас; idx 13–25 —
  бас ±6 + фикс. **+4 дБ полка @180 Гц** и **+3 дБ @4000 Гц** (профиль с
  компенсацией середины/верха).
- **TrebShelf** — 13 инстансов: полка (type 3) @10 кГц, −6…+6 дБ, шаг 1 дБ.
- **Desk_Acoustic_2** — 11 инстансов: пикинг @200 Гц Q=2 −4 дБ (гашение
  резонанса стола) × полка @500 Гц 0…−4 дБ (2D-сетка 2×5+1).
- **EQDIY / EQDIY_2 / EQ17 / EscoDlEq** — плоские (0 дБ) — слоты
  пользовательского EQ (заводское значение) и call-EQ.
- Каждый набор = 12 бандов: 10 полос лестницей ~24…21600 Гц
  (шаг ≈2.1×) + фикс. полка @40 Гц (type 7) и @18 кГц (type 8), Q=0.7.
  type 0 = bypass (EscoUlEq банды 0–1).

## 2. Кривые громкости по источникам (тип 3, блоки 136 Б = 4 заголовка + 30 значений дБ)

| узел | кривая, дБ | макс |
|---|---|---|
| Vol_BtmMusic (BT) | −70 … −7 | −7 |
| Vol_BtmMusic2 | −63 … −5 | −5 |
| Vol_LinMusic (line-in) | −63 … 0 | 0 |
| Vol_LinMusic2 | −58 … 0 | 0 |

⇒ у каждого источника своя 30-ступенчатая dB-кривая и свой максимум
(цифрового запаса у BT меньше, у line-in больше — выравнивание источников).
Vol_SysTone/KTone/Ring/BtcCall/PcspkMusic — блоки 16 Б (сырые u32, не float).

## 3. Выходные гейны (тип 3, блоки 12 Б, 2 записи: макс/мин)

- SET_HP_GAIN: **+8.3 / −90.3 дБ**; SET_HP_GAIN2: **+2.3 / −90.3**
- AUX_DAC_GAIN: **0 / −1.3**; AUX_DAC_GAIN2: **+6.5 / 0**

−90.3 дБ ≈ цифровое «выключение» → плавный mute/fade диапазоном узла.

## 4. set_hp_gain (sub_06006390) — механизм применения громкости

- RAM-состояние @0x106060; счётчики b[+20]/b[+21]/b[+22] с клампами
  **51 / 24(8/15/23 внутр. зоны) / 51**; watchdog-счётчик [r5+228] ≤ 60000.
- Режим источника: sub_060745c6() → байт режима (49='1', 51…53).
- param_2 ∈ {0,1,2} — направление; helpers sub_0600605e/06006068/
  06006132/060061fc/060062c6 — **битбанг GPIO 0x00FD5008**: пины-биты
  **0x2, 0x8, 0x40**, запись `[port]|=bit` и `[port+8]&=~bit` с udelay
  между операциями ⇒ 3-проводной последовательный интерфейс на внешний
  узел усиления (цифровой потенциометр/усилитель), разные последовательности
  на шаг вверх/вниз/сброс. Вывод: громкость применяется пошагово
  (аппаратный fade), 0…51 шагов на канал.
- Периодический таск sub_0600657c: счётчик до 200, на 100 — секвенция
  GPIO-записей @0x00FD5010 (биты 0/4/8/12) — питание/unmute-порядок
  (защита от щелчков при старте).

## 5. Защитные узлы (пул типов плагинов @0x05fd0f…0x05fde6)

`mixer, decoder, resample, play_sync, capture_sync, bt_audio_sync,
sound_splitter, eq, wdrc, steromix, gain, bit_width_convert,
energy_detect, channel_merge, channel_expander, data_saturation, wav,
audio_dac` — включая **wdrc** (широкополосный DRC/лимитер → узлы
MusicDrc/DRC5/DRC31), **energy_detect**, **data_saturation** (клип/сатурация
против переполнения), **channel_expander** (2→4 канала на би-ампинг).

- Конфиг DRC5/DRC31 (76 Б float): [0, 0, −1.6, −1.6, 135.4, 135.4, 158.4,
  135.4, 138.4×6, 0, 0, 25, 0, 0] — семантика полей не подтверждена.
- Тональная рампа-таблица @app.bin 0x060FF0..0x0614AE: треугольник
  0…127…0 (с 6-байтной шапкой) — кандидат fade/дыхания; потребитель
  не найден (без mov32-ссылок).
- Тон максимума громкости: `tone_zh/vol_max.*` в таблице тонов режимов
  (0x0606251c..0x060626b6), игроки sub_0600ba7c / sub_0600f55c.
- MIC-конфиг MIC534361: мин. гейн −70 дБ (1.0…−70.0…2.0).

## 6. Клавиши/энкодер

sub_06002224 (key_scan_send): дебаунс, автоповтор (пороги 3000/5000 мс,
шаг ×10 мс), таблица состояний (key×8+1136), отправка BLT+BUTTON+IO1..6;
коды клавиш 65/66 ('A'/'B') — отдельные ветки.

## 7. Не разобрано

Семантика DRC-флотов; назначение 3 пинов GPIO (какой чип снаружи);
заголовки Vol_-блоков (4 слова); tag 0 w-семантика и TLV 3/6/8/10;
типы дескрипторов 7; групповые записи 04/05/07; дальние call (ROM/банк).
