2 · Источник / режим (effect_nodes_open) и мьюты трактов

Мьют источника (gain-пейлоад −90.3 дБ):
Мьют = генерация 12-байтного gain-параметра (0xa904: 8×00 + f32 дБ) для узла тракта + попытка доставки: BLE-кадром (если аппарат принимает node_param_set по app-каналу) либо как cfg-DB blob (кнопка в лаборатории).

3 · HP → SUB-OUT визард

Нажми «Собрать» — сгенерирую 12-полосный LPF-блок (type 1 lowpass1) для EQDIY-слота + SET_HP_GAIN-пейлоад.
⚠ Разделительные конденсаторы HP-выхода при низкоомной нагрузке (4–8 Ом) дают fc ≈ 90–180 Гц — НЧ срежется. SUB из HP-выхода годится только на высокоомный вход сабового усилителя (≥10 кОм).

0x44/0x46 — app-протокол (до 9 полос, gain-байт). 200-байтный блок — нативный формат node_param_set(0x737b)/cfg-DB (12 полос, type 0–8, f32).

7 · Лаборатория: crc16 (djb2) + cfg-DB запись

—
Ключ узла: {type, crc16 = djb2(имя ШАБЛОНА; seed 0x1505, ×33), param}. Проверено по stream.bin: EQ=0x737B, Gain=0xA904, DAC=0xDCCD, DRC=0xDEFE, ADC=0xD06D. Запись cfg-DB — FUN_06037cce, чтение — 06037ba4; cfg-DB приоритетнее заводских значений stream.bin.
