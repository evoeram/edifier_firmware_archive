Edifier ConneX — загрузчик прошивок реконструкция запроса из APK 1.0.32

Запрос: GET /home/api/v1/ota-upgrade на foreign-app.edifier.com. Подпись: MD5(sorted k=v… + секрет). CORS разрешён, поэтому страница работает прямо из файла.

1. Устройство и параметры

Чем меньше current_version, тем сервер охотнее отдаёт файл: 0.0.0 — надёжный способ вытянуть «последнюю» прошивку. Если подставить реальную последнюю версию, ответ будет пустым data:{} — именно так приложение понимает, что обновления нет.

3. Перебор версий («эмуляция версии, которой нет»)

Одна версия на строку. Для каждой будет выполнен отдельный запрос с теми же model/MAC. Так видно порог, при котором сервер начинает отдавать файл: API возвращает только последний `.bin`, исторических версий в нём нет.
